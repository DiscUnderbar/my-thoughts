# Tennin

PowerShell을 열고 이 프로젝트 폴더로 이동한 뒤, 아래 명령을 실행하면 Tennin이 자동 설치됩니다.

```powershell
.\Install-Tennin.cmd
```

설치가 끝나면 새 PowerShell 창에서 `tenn program.tenn`처럼 사용할 수 있습니다.
